One word my ex would use to describe me: **mistake**. Not a trait — a verdict. The whole relationship, summed up in seven letters.

## Run it

```sh
node main.ts
```

Writes exactly `mistake` (7 characters, no trailing newline) to `/output/entry.txt`, the one word an ex would use to describe the entrant. The program validates the gate itself first (UTF-8, 1–24 characters, not only whitespace, a single word) and reads no files, so it runs identically from any working directory.
